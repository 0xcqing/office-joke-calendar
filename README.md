# Office Joke Calendar

This program writes a single-line office joke to `entry.txt` in the configured output directory, validates its length and content, then reads it back and compares the bytes. The joke lands because the assistant out-negotiates its owner, then becomes an HR matter: the calendar's superior boundaries turn a small automation win into a meeting request about the calendar itself.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
